Real-time Digital Human Streaming

Industry–Academia

2026.07 – PRESENT

Real-time streaming output for a talking-avatar generator, replacing offline batch rendering.

Overview

The model renders a complete video only after every frame is generated, which prevents real-time use in a live digital-human demo.

Role

Deployment, latency analysis, output-pipeline redesign, and the browser-side media receiver.

Outcome

First-frame wait reduced by more than half, with output identical to the original pipeline.

The delay traced to the final "render everything, then convert" step rather than the model, which remains unmodified. Schematic, not to scale.Concept illustration · no project code or data
