Real-time Digital Human Streaming

Industry–Academia

2026.07 – PRESENT

Real-time streaming output for a talking-avatar generator, replacing offline batch rendering.

Overview
The open-source talking-head model renders a complete video only after every frame has been generated, which prevents real-time use in a live digital-human demo. The goal is to deliver frames to the browser as they are generated.
Role
Deployment, latency analysis, output-pipeline redesign, and the browser-side media receiver.
Approach
  • Reproducible setup: one-command installation, verified on RTX 3060 and RTX 4090.
  • Stage-by-stage timing before any change; the delay traced to the final "render everything, then convert" step rather than the model.
  • Per-frame encoding and transmission as each frame is generated, with audio paced by generation speed to keep sound and picture in sync. The model itself remains unmodified.
Validation
Frame-by-frame comparison against the original pipeline output, identical across the full test clip.
Outcome
First-frame wait reduced by more than half.
  • Python
  • PyTorch
  • Video streaming
  • WebRTC
  • GPU deployment

Fact-grounded Content Generation for a Travel Game

Industry–Academia

2026.09 – PRESENT

An LLM writing pipeline in which every sentence traces back to a stored fact.

Overview
A travel game requires a large volume of location-based story content. LLM output is fluent but can contain fabricated details, so the content must be both engaging and traceable to a source.
Role
Data collection and design of the generation and review process.
Approach
  • Government open data crawled into a validated, duplicate-free database, covered by unit tests.
  • Mandatory fact citation for every generated sentence, with writing style controlled through personas.
  • Proposed asynchronous backend with token authentication for the mobile app.
Validation
Sentence-level audit by an AI reviewer against each cited source, with automatic-fail rules. The reviewer is calibrated against human ratings and regression-tested on a fixed reference set.
Outcome
A generation process in which every sentence is traceable and auditable.

  • Pydantic
